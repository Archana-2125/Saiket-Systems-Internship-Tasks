# Task 5 - Currency Converter

A simple Currency Converter application developed using Python and Tkinter.

## Features

- Convert between different currencies
- Uses an exchange rate API
- User-friendly graphical interface
- Supports multiple currencies
- Handles invalid input
- Handles API connection errors
- Clear button to reset the input

## Technologies Used

- Python
- Tkinter
- Requests
- Exchange Rate API
