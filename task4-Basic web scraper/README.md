# Task 4 - Basic Web Scraper

## Description

A Python-based web scraper that extracts news headlines and their URLs from a website using Requests and BeautifulSoup.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- HTML Parsing

## Features

- Fetches webpage data
- Extracts news headlines
- Extracts article URLs
- Displays the top 10 headlines
- Handles request errors

## How to Run

Install the required packages:

```bash
pip install requests beautifulsoup4
