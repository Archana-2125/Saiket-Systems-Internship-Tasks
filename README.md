# Task 2 - Guess the Number Game

## Description

A simple Python-based Guess the Number game where the player tries to guess a randomly generated number between 1 and 100.

## Features

* Generates a random number between 1 and 100
* Gives the user 7 attempts
* Provides hints such as **Too High** and **Too Low**
* Displays a congratulatory message when the correct number is guessed
* Displays the correct number if all attempts are used
* Counts and displays the number of attempts

## Technologies Used

* Python
* Random Module

## How to Run

```bash
python guess_number.py
```

## Game Flow

1. The program generates a random number between 1 and 100.
2. The user gets 7 attempts to guess the number.
3. The program provides a hint after each incorrect guess.
4. The game ends when the correct number is guessed or all 7 attempts are used.
